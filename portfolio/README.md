# Ayan Shaikh Portfolio

A bold, responsive developer portfolio for Ayan Shaikh — BCA graduate, software developer and full-stack learner from Ahmedabad, India.

## Highlights

- Editorial black, white and red visual system
- Responsive hero, skills, work history, projects, education and contact sections
- Expandable project stories
- Accessible navigation and reduced-motion support
- Image placeholders ready for Ayan's portrait and project screenshots

## Local development

Requirements: Node.js 22.12 or newer.

```bash
npm ci
npm run dev
```

## Release checks

```bash
npm run check
npm run build
```
